## Download / 下载

Download **TheyAreBillionsSaveManager-v0.2.0-windows.zip**, extract it and run **Start.cmd**. The standalone **TheyAreBillionsSaveManager.exe** also runs directly. Windows 10 / 11; no installer or extra runtime download required. **Source code** downloads are for building the program yourself.

下载 **TheyAreBillionsSaveManager-v0.2.0-windows.zip**，解压后双击 **Start.cmd**；也可直接下载并运行独立 **EXE**。支持 Windows 10 / 11，无需安装或下载额外运行环境。**Source code** 是源码，不是可直接运行的程序。

## What's new / 本次更新

- English and Simplified Chinese, automatic display-language detection, instant switching and saved language preference.
- Automatic snapshot retention, historical restore points and a restore flow that accounts for Steam startup synchronization.
- Application errors and legacy snapshot reasons follow the selected language.
- Bilingual instructions and SHA-256 checksums.

- 中英文界面，自动识别显示语言，支持即时切换和记住选择。
- 自动保留快照、历史恢复点，以及处理 Steam 启动同步的回退流程。
- 工具错误与旧快照原因随语言切换。
- 双语说明及 SHA-256 校验文件。

**Restore:** exit the game → choose a restore point → **Launch & restore** → wait at the main menu → click Continue only when the tool says it is ready.

**回退：** 退出游戏 → 选择恢复点 → **启动游戏并回退** → 停在主菜单等待 → 工具提示就绪后再点继续。

Only existing disk saves can be restored; an exact five-minute rollback is not guaranteed. 只能恢复已有的磁盘保存点，无法保证精确回退五分钟。
