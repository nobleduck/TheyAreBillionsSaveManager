## Fixed / 修复内容

Fixed the repeated button flicker while the tool is idle. The once-per-second game-state check no longer temporarily disables every control. Automatic snapshot and restore operations retain their operation locks, and the restore button still follows whether the game is running.

修复助手空闲时按钮持续闪烁的问题：每秒检查游戏状态不再反复禁用、启用所有控件。自动备份及回退时仍保留操作保护，游戏启动或退出时仍正确更新回退按钮。

Close the tool, download **TheyAreBillionsSaveManager-v0.2.1-windows.zip**, extract it and run **Start.cmd**. The standalone **TheyAreBillionsSaveManager.exe** is also available. Existing snapshots and language settings are retained.

关闭助手，下载 **TheyAreBillionsSaveManager-v0.2.1-windows.zip**，解压后运行 **Start.cmd**；也可下载独立 **EXE**。已有快照和语言设置会保留。
